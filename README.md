# Manidhar Boddu — Portfolio

Single-page professional portfolio for Senior Data Engineering, Analytics, and Data & AI roles.

## Preview locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

This is a static site and can be deployed directly to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static web host.

## Update later

- `index.html` — content
- `styles.css` — visual design
- `script.js` — navigation and reveal interactions
- `assets/manidhar-profile.webp` — portrait
- `assets/Manidhar_Boddu_Resume.docx` — downloadable resume

A dedicated side-project section can be added later once project names, screenshots, live URLs, and GitHub links are available.


## Portfolio coverage
The site highlights Microsoft Fabric, Microsoft Azure / Databricks, AWS cloud engineering, Snowflake, big-data streaming, analytics & BI, Data & AI, and DevOps / reliability experience.
