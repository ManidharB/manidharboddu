JOBHUNTERX — DISCOVERY API KEYS
================================

OMNI WEB SEARCH (recommended for broad coverage)
Brave Search API
https://brave.com/search/api/
Create a Search API subscription token. Brave currently includes monthly free credits on Search plans.
JobHunterX uses this only as a web-wide discovery index, then hydrates public job pages and learns direct ATS boards.

JobsPipe
https://jobspipe.dev/
Use a JobsPipe API key prefixed with jp_live_.

Jooble U.S. API
https://jooble.org/api/about
A key created on jooble.org is for the U.S. regional API.

Adzuna Developer API
https://developer.adzuna.com/
You will receive an App ID and App Key.

USAJOBS Developer API
https://developer.usajobs.gov/
Request a search API key. JobHunterX also needs the email used for that API request.

No personal search key is needed for public employer boards learned/configured through Workday, Greenhouse, Lever, or Ashby. SmartRecruiters public-board behavior varies by company/access.

Never paste API secrets into chat. Put them only in JobHunterX -> Settings & Sources -> Free APIs.
