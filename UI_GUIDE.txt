
CONTINUOUS SEARCH
-----------------
Go to Settings & Sources -> Continuous Search.
Enable continuous background search, choose an interval (24 hours is recommended), then click Install / Start continuous search.
There is no seven-day expiry. Job history remains in SQLite indefinitely.
The first run can backfill older jobs; later runs use a small overlap window so API credits focus on new listings.

JOBHUNTERX — UI QUICK GUIDE
===========================

START
-----
Mac: ./START_JOBHUNTERX_MAC_LINUX.sh
Windows: START_JOBHUNTERX_WINDOWS.bat

MAIN PAGES
----------
Command Center          Find, score, tailor, and process applications.
Job Queue               Filter jobs by fit, visa fit, status, location, work arrangement, or source.
Sponsorship Intelligence Configure visa-aware ranking and sync official DOL LCA employer history.
Resume Manager          Upload/replace the master DOCX without touching project files manually.
Review Desk             Resolve CAPTCHA, MFA, legal, missing-answer, and sponsorship blockers.
Applications            Track attempts, confirmed submissions, and follow-ups.
Profile & Answers       Store only verified application facts.
Settings & Sources      Configure U.S. targeting, free APIs, direct ATS feeds, web discovery, and safety.
Activity Log            Troubleshoot provider/browser issues.

DAILY FLOW
----------
1. Find Jobs
2. Score + Visa
3. Review top opportunities in Job Queue
4. Tailor
5. Apply / Review
6. Resolve Review Desk blockers

FREE SOURCE SETUP
-----------------
Settings & Sources -> Free APIs
Paste any keys you obtain for JobsPipe, Adzuna, Jooble, and USAJOBS.
You do not need every key at once. Every configured provider runs independently.

SPONSORSHIP
-----------
Profile & Answers -> set the verified sponsorship answer.
Sponsorship Intelligence -> choose the filter policy.
Optional: Sync latest DOL LCA history to build a local employer-sponsorship history index.

AUTO-SUBMIT
-----------
Keep it locked until you have verified several real applications.
Even when unlocked, CAPTCHA, MFA, legal attestations, unknown required fields, and incompatible sponsorship signals can stop automation.
