JOBHUNTERX ADAPTIVE ROLE INTELLIGENCE
=====================================

Open the UI -> Settings & Sources -> Targeting.

Role Search Mode:
- Adaptive — based on resume: the active master resume chooses the search roles.
- Hybrid — resume + preferred roles: adaptive roles plus anything you type in Preferred/manual roles.
- Manual — exact list: uses only the roles you type.

Recommended:
- Mode: Adaptive — based on resume
- Expansion: Balanced
- Minimum inferred-role confidence: 78%
- Maximum active search roles: 18
- Learn relevant role titles from high-fit jobs: ON
- Minimum job score for role learning: 85%

The Active Role Universe table on the same page shows exactly what roles JobHunterX will use.
Changing the master resume in Resume Manager causes the role universe to be recalculated after refresh/restart.

The manual role box is intentionally ignored in pure Adaptive mode.
